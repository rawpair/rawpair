RawPair brings a shared editor, a persistent terminal and private HTTPS application previews to your own Ubuntu host. Native packages include the matching Orqos execution service for Ubuntu 24.04 on amd64 and arm64.

Start with docs/PACKAGES.md in this release's source tree: download this release's install.sh, inspect it, and run it as your ordinary user with --version set to this tag. Setup walks through local or remote access, the database and your first login. Then follow docs/FIRST_WORKSPACE.md to serve a small page, edit it together and bring a coworker into the same workspace.

The package guide also covers manual checksum checks, optional GitHub provenance verification, backups, upgrades and explicit migration from older installations. This is a pre-alpha for trusted collaborators on one Linux host; see docs/PACKAGE_HANDOFF.md for validation limits.
